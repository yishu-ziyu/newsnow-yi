## 四个坑（+1），都值得记住

1. **Vercel 上被强制跑 Edge Runtime**。上游 `nitro.config.ts` 在 `process.env.VERCEL` 分支写死 `nitroOption.preset = "vercel-edge"`。Edge 没有 `node:net`/`node:crypto`，Postgres 驱动直接不可用。→ 改成 `"vercel"`（Node.js）。判断依据：`.vercel/output/functions/__nitro.func/.vc-config.json` 里 `runtime` 是 `edge` 还是 `nodejs22.x`。
2. **nitro 的 `database` 配置在部署环境静默失效**。它按连接器**名字**在运行时动态 import，Vercel 函数产物里没有 `node_modules` → import 失败 → 错误被 `getCacheTable()` 的 try/catch 吞掉 → 表现是"缓存永远不生效、`/api/s/entire` 一直 204/空"。→ 改成自己静态 import 连接器 + `createDatabase()`（`server/utils/database.ts`）。
3. **`better-sqlite3` 不能在函数入口出现**。它是原生模块，Vercel 镜像里是 macOS 编的二进制；入口的 `import "better-sqlite3"` 会在启动时加载 → `FUNCTION_INVOCATION_FAILED`。→ 本地改用 Node 内置 `node:sqlite`（懒加载）。
4. **Postgres 与 SQLite 的差异**：`INTEGER` 存不下毫秒时间戳（→ `BIGINT`）；`user` 是保留字（→ `"user"`）；`INSERT OR REPLACE` 不存在（→ `ON CONFLICT(id) DO UPDATE`）；`?` 占位符要转 `$1..$n`（连接器里做）。
5. **全站 ISR 会把 `/api/s` 搞坏**。上游 `routeRules` 里 `"/**": { isr: 3600 }`，实测 `/api/s` 被包成 ISR 函数后稳定 `FUNCTION_INVOCATION_FAILED`（同一份产物本地 `node index.mjs` 跑是 200）。源数据已有数据库缓存，不需要 ISR → 已改成普通 `cache-control` 头。

**诊断"函数 400 / FUNCTION_INVOCATION_FAILED"的套路**（这次就是靠它定位的）：
- 临时加一个诊断接口，**路径要落在中间件白名单里**（例如 `server/api/s/debug-db.get.ts`），把每个步骤单独 try/catch 后返回结果，逐步复刻可疑路由的流程；
- Vercel 面板 → 项目 → Logs 看每次请求的 message（CLI 的 `vercel logs -d <deployment>` 常常流不出东西）；
- 本地复现同一份产物：`node .vercel/output/functions/__nitro.func/index.mjs`（本机默认 Node 恰好与 Vercel 同为 22.x，很省事）。

3. **品牌素材**：`public/icon.svg`、`apple-touch-icon.png`、`pwa-192x192.png`、`pwa-512x512.png`、`og-image.png` 仍是上游素材，替换清单和导出方式见 `docs/rebrand.md`。

5. **UI 评审 01 的 C 档**：卡内滚动的显式入口（现在只有底部渐隐）、卡片等权布局。见 `docs/ui-review-1.md`。
6. **`dist/` 里有被 git 跟踪的构建产物**（`.vercel`/`.nitro` 相关）；`pnpm build` 后 `git status` 会一直脏。建议 `git rm -r --cached dist`（文件留在磁盘，只是不再跟踪）。
7. **本地开发别连生产库**：不要在 `.env.server` 里放 `DATABASE_URL`，否则本地会往线上写数据。本地默认 SQLite（`.data/db.sqlite3`）。

## 本地开发

```bash
pnpm install
cp example.env.server .env.server      # 至少填一个 LLM key
pnpm dev                                # 固定 127.0.0.1:5173（--strictPort，端口被占会直接报错）
```

`http://localhost:5173` 与 `http://127.0.0.1:5173` 都会到这个 dev server（别被"两个地址"迷惑）。本地数据库是 `.data/db.sqlite3`。
